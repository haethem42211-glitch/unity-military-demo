# Unity Military Demo (FPS) — Starter

مشروع تجريبي بسيط لنمط FPS (إطلاق نار أول شخص) مخصص كنقطة بداية للعبة عسكرية.

المحتوى الموجود في هذا الريبو:
- Assets/Scripts/PlayerController.cs — سكربت تحكم باللاعب (حركة، تصويب بالفأرة، صحة، تفاعل مع السلاح)
- Assets/Scripts/Weapon.cs — سكربت سلاح بسيط (تصويب برشاش بنظام ريسكاست، ذخيرة، إعادة تحميل)
- Assets/Scripts/EnemyAI.cs — ذكاء اصطناعي بسيط للأعداء (مطاردة، إطلاق نار مسافة قريبة)
- Assets/Scripts/HUDController.cs — تحكم بعرض الصحة والذخيرة على الشاشة
- README.md — تعليمات ضبط المشروع خطوة بخطوة

المواصفات الموصى بها:
- إصدار Unity: 2022.3 LTS
- نمط: 3D، Single-player
- ترخيص: MIT
